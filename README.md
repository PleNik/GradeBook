# **Построение класса GradeBook**
1. Первый пример представляет класс **ШGradeBook** с одним методом, который при вызове просто выводит приветственное сообщение.
2. Второй пример модифицирует первый, позволяя методу принимать название курса в качестве аргумента. Затем метод выводит 
полученное название курса как часть приветственного сообщения.
3. Третий пример показывает, как сохранить название курса в объекте **GradeBook**. В данной версии класса показано как использовать методы для установки названия курса в объекте и получения названия из объекта.
4. Четвертый пример демонстрирует, как данные в объеке **GradeBook** могут быть инициализированы при его создании при помощи конструктора класса. Пример также показывает, что каждый объект **GradeBook** хранит в своем атрибуте собственное название курса.
5. Пятый пример модифицирует четвертый, демонстрируя, как, в целях утилизации, разместить класс **GradeBook** в отдельном файле.
6. Шестой пример модифицирует пятый в соответствии с одним из принципов правильного конструирования программ, а именно, принципом отделения интерфейса класса от его реализации. Это облегчает модификацию класса, которая в этом слуючае не влияет на *клиентов класса*, т.е. любых классов или функций, извне вызывающих методы объектов класса.
7. Последний пример усовершенствует класс **GradeBook**, вводя в него подтверждение действительности данных, гарантирующих, что данные в объекте соответствуют определенноме формату или находятся в допустимом диапазоне значений. Например, объект **Date** требовал бы, чтобы значение месяца находилось в диапазоне 1-12. В этом примере класса **GradeBook** метод, устанавливающий название курса, подверждает, что название курса состоит из 25 или меньшего числа символов. Если это не так, метод берет только первые 25 символов названия и выводит предупреждающее сообщение.
8. Введен второй элемент данных string, представляющий имя преподавателя, ведущего курс. Добавлен set-метод для изменения имени преподавателя и get-метод для его извлечения. Имя преподавателя передается в конструктор. Метод displayMessage выводит кроме приветствия и названия курса, еще и имя преподавателя.
9. Добавлен метод *DetermineClassAverage*, который усредняет введенные оценки в группе студентов.
10. Метод *DetermineClassAverage* модифицирован. При каждом запуске он обрабатывает оценки для произвольного числа студентов. Тип данных для среднего значения изменен на *double*. Предусмторен гарантированный вывод десятичной точки среднего значения путем применения манипулятора потока *fixed*. Значение средней оценки выводится с точностью до двух цифр путем применения манипулятора потока *setpresition*.
11. Новая версия класса просит пользователя ввести ряд буквенных оценок (метод *void inputGrades()*) и затем выводит сводку числа студентов, получивших каждую из возможных оценок (метод *void displayGradeReport()*). Введены дополнительные поля класса: *int aCount*, *int bCount*, *int cCount*, *int dCount*, *int fCount* - числа оценок в каждой категории A, B, C, D, F.
12. В метод *void inputGrades()* добавлен расчет средней оценки класса. Вес оценки 'A' - 4 пункта, оценки 'B' - 3 пункта и т.д.
